Framework 开源框架

EvolveX

EvolveX is an open-source framework for self-evolving agents, built by Simple Agent Lab. It helps you build agents that improve and keep the evidence—so every improvement stays simple, transparent, and verifiable. EvolveX 是 Simple Agent Lab 开发的自进化智能体开源框架。它让智能体持续改进，并保留改进的证据——让每一次改进都保持简单、透明、可验证。

What EvolveX does EvolveX 做什么

Most agent systems improve as a black box: something changed, metrics moved, and no one can say why. EvolveX treats agent evolution as an auditable process. Agents propose improvements, run them, evaluate the results, and record the evidence behind every change—so humans can inspect how an agent got better and decide where it goes next. 多数智能体系统的改进像一个黑盒：东西变了、指标动了，却没人说得清为什么。EvolveX 把智能体进化视为一个可审计的过程：智能体提出改进、执行改进、评估结果，并记录每次变化背后的证据——让人们能够检查智能体如何变好，并决定它的下一步。

Why we built it 为什么构建它

EvolveX is part of our research on AI4AI and recursive self-improvement: a future where AI helps build AI, while the methods behind it remain understandable to humans. EvolveX is our simple-yet-effective answer for the agent layer of that loop. EvolveX 是我们在 AI4AI 与递归自我改进方向研究的一部分：让 AI 帮助创造 AI，同时让背后的方法始终能被人类理解。EvolveX 是我们在智能体这一层给出的 simple yet effective 的答案。

Get started 开始使用

EvolveX is written in Python and released under the Apache 2.0 license. Browse the source code on GitHub or read the EvolveX documentation to get started. EvolveX 使用 Python 编写，以 Apache 2.0 协议开源。你可以在 GitHub 上浏览源码，或阅读 EvolveX 文档开始使用。
